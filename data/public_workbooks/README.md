# Public analytical Excel workbook

File: `Medical_AI_Agents_Public_Analytical_Workbook_v1.0.4_20261014.xlsx`

This workbook exports the v1.0.4 analytical dataset into a reader-accessible Excel format. It includes 26 worksheets with 54-report coding, 1,242 safeguard records, safety outcomes, metric categories, bibliographic metadata, coding definitions, denominators, funding reporting and aggregate reliability results. Final consensus screening decisions cover 132 assessed records, including excluded records; the synthesis denominator remains 54. A focused table summarizes ten current borderline eligibility decisions.

Original A/B workbooks, source quotations, internal adjudication logs, local filesystem paths and patient-level records are excluded. Aggregate agreement and kappa describe the original independent coding, not later analytical adjustments.

The underlying dataset is archived as v1.0.4 at https://doi.org/10.5281/zenodo.23366100. This Excel file was prepared and added after that release; it is not yet contained in that archived snapshot. Adding it to the current main branch does not modify the v1.0.4 tag or its Zenodo archive.
