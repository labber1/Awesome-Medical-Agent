# Dataset version history

## v1.0.4 - October 14, 2026

Synchronizes the public dataset with the current 54-report analysis and English appendix explanations. This publication exports approved analytical values; it is not a new independent coding round or a new primary-source verification.

- Source coverage is Complete 1, Partial 16, Unclear 37, replacing the old 11/9/34 distribution.
- Applicable temporality is n=46: Retrospective 12, Prospective 1, Mixed 1, Unclear 32; 8 Not applicable.
- Controlled workflow is Yes in 15 reports. Operational use and patient-care impact have no confirmed positive classifications.
- Separate design/allocation variables replace the obsolete randomized/non-randomized controlled hierarchy. Three randomized allocation evaluations are not patient randomized trials.
- Current approved human/design and safeguard adjustments are included. Safeguard report counts are 44/40/30/40/0 for reporting, implementation, empirical evaluation, evaluated-setting use and real-world use.
- Original A/B coding and its reliability statistics are unchanged. Reviewer verification of revised classifications is not treated as a new reliability estimate.
- AutoCT and VivaBench citations use the formal EMNLP/NeurIPS 2025 publications; extraction URLs identify the preprint versions actually used. Extracted report type remains separately recorded.
- Source quotations, private files, internal audit trails and raw A/B workbooks are not redistributed.
